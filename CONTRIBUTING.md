# Contributing to LogPose

First off, thanks for taking the time to contribute! 

## Code of Conduct
This project and everyone participating in it is governed by the LogPose Code of Conduct. By participating, you are expected to uphold this code.

## How Can I Contribute?
### Reporting Bugs
Before creating bug reports, please check the existing issues. When you are creating a bug report, please include as many details as possible.

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues.

### Pull Requests
- Fill in the required template.
- Do not work directly on `main`.
- Ensure tests pass.

## Styleguide
We follow the official Kotlin Coding Conventions.
