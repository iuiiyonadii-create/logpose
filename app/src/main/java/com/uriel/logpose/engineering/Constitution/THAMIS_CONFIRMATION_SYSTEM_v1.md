# THAMIS CONFIRMATION SYSTEM v1.0

## 1. Gramática Soportada
El motor reconoce variantes naturales para las confirmaciones:
- **AFIRMATIVO**: "Sí", "Dale", "Hacelo", "Ok".
- **NEGATIVO**: "No", "Para nada", "Mejor no".
- **CANCELACIÓN**: "Cancelá", "Pará", "Basta".

## 2. Acciones de Seguimiento
El sistema permite posponer acciones:
- "Esperá": Pausa la conversación por 10 segundos adicionales.
- "Después": Encola la notificación para el final del viaje.
