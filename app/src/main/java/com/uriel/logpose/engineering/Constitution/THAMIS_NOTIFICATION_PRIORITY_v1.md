# THAMIS NOTIFICATION - POLÍTICA DE PRIORIDAD v1.0

## Jerarquía de Lectura
1. **CRITICAL**: Alertas de vida, accidentes, batería < 5%. (Interrupción inmediata).
2. **HIGH**: Navegación, llamadas perdidas, alertas de velocidad.
3. **NORMAL**: Mensajes de texto, WhatsApp de contactos frecuentes.
4. **LOW**: Notificaciones sociales, correos no urgentes.
5. **SILENT**: Registro en historial sin aviso sonoro.

## Factores de Ajuste
- **Frecuencia**: Si una app satura de notificaciones, el sistema degrada su prioridad automáticamente.
- **Contexto**: En modo Ciudad, la navegación tiene prioridad máxima; en modo Ruta, se priorizan las alertas de vehículo.
