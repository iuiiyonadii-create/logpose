# THAMIS WORLD - MÉTRICAS DE CONTEXTO v1.0

## 1. KPIs de Salud
- **Update Frequency**: Cantidad de actualizaciones por minuto.
- **Inconsistency Rate**: % de estados que fallaron la validación inicial.
- **Engine Latency**: Tiempo promedio de procesamiento del Reducer (Objetivo < 5ms).

## 2. Métricas de Disponibilidad
- **Provider Uptime**: Tiempo que cada dominio ha estado informando datos válidos.
- **State Integrity**: Salud promedio de los sub-estados del mundo.
