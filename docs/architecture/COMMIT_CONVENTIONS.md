# Commit Conventions

We follow **Conventional Commits 1.0.0**.

## Format
`<type>(<scope>): <short summary>`

## Types
- `feat`: A new feature
- `fix`: A bug fix
- `docs`: Documentation changes
- `test`: Adding or updating tests
- `refactor`: Code changes that neither fix bugs nor add features
- `chore`: Maintenance tasks, dependencies updates

## Examples
- `feat(core-common): implement LabResult sealed interface`
- `docs(adr): add ADR-001 for engineering foundation`
