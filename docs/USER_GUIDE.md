# LogPose User Guide

## 1. Getting Started
1. Install the LogPose APK.
2. Grant all requested permissions:
   - **Bluetooth**: To connect to your helmet.
   - **Microphone**: For voice commands.
   - **Notifications**: To read messages aloud.
3. Turn on your Intercom and pair it with your phone.

## 2. Voice Commands
Always start with the keyword: **"LogPose"**
- "LogPose reproducir" -> Start music.
- "LogPose pausa" -> Pause music.
- "Siguiente" -> Next track.
- "Subir volumen" -> Increase volume.

## 3. Driving Modes
- **Normal**: Full assistance (Music + Messages + Navigation).
- **Focus**: Restricted mode (Only Navigation and Critical Calls).
- **Private**: No reading aloud (Silent mode).

## 4. Troubleshooting
- If voice isn't heard: Check if the SCO channel is active on your intercom.
- If music doesn't pause: Ensure your media player (Spotify/YT) has notification access enabled.
