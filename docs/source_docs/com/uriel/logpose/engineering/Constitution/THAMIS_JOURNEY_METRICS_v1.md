# THAMIS JOURNEY - MÉTRICAS v1.0

## 1. KPIs de Operación
- **Total Transitions**: Cantidad de cambios de estado realizados.
- **Average Confidence**: Promedio de confianza de las transiciones confirmadas.
- **Transition Latency**: Tiempo entre el evento físico y el cambio de estado en THAMIS.

## 2. KPIs de Negocio
- **Moving Time**: Tiempo total de conducción neta.
- **Stopped Time**: Tiempo total en semáforos o detenciones breves.
- **Duty Cycle**: Relación entre tiempo en movimiento y tiempo total de la sesión.
