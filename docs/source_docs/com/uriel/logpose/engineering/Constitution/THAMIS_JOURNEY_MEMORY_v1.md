# THAMIS JOURNEY - MEMORIA v1.0

## 1. Persistencia de Sesión
El módulo `JourneyMemory` almacena:
- ID único del viaje (UUID).
- Timestamp de inicio y fin.
- Ubicación de origen (aproximada).
- Velocidad máxima alcanzada.
- Distancia total acumulada.

## 2. Reutilización Cognitiva
Los datos en memoria permiten que THAMIS responda preguntas como:
- "¿Cuánto manejé hoy?"
- "¿A qué hora llegué?"
- "¿Cuál fue mi velocidad máxima en el último tramo?"
