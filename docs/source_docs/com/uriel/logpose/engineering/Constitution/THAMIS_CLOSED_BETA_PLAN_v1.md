# THAMIS Closed Beta Validation Plan v1.0

## 1. Objetivos de la Beta
El propósito de esta fase es validar el comportamiento de THAMIS en un entorno de producción real (calle, ruta, tráfico). No se buscan nuevas funciones, sino confirmar que el sistema actual es seguro y útil.

## 2. Métricas de Éxito
- **Regla del 1%**: El usuario no debe mirar la pantalla del celular más de un 1% del tiempo total del viaje.
- **Safety Score**: Promedio superior a 0.85 en todas las sesiones.
- **Helpfulness**: Valoración media de los usuarios superior a 4/5.

## 3. Escenarios de Prueba
- **Ciudad**: Semáforos, ruido de bocinas, cambios rápidos de dirección.
- **Ruta**: Alta velocidad, ruido de viento constante, señal de GPS variable.
- **Delivery**: Alta carga de notificaciones y mensajes entrantes.

## 4. Recopilación de Feedback
Tras cada viaje, el sistema solicitará una valoración rápida por voz para registrar la satisfacción y detectar puntos de fricción auditiva.
