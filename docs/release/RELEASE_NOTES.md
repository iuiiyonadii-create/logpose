# LogPose Release Notes v1.0.0-beta

## What's New
- **THAMIS Core Engine**: First implementation of the context-aware decision orchestrator.
- **Hands-Free Music**: Command your player via voice ("LogPose reproducir/pausa/siguiente").
- **Smart Message Filter**: LogPose reads urgent messages but stays silent during complex turns.
- **V6 Pro Optimization**: Specialized bluetooth profiles for high-performance intercom link.
- **Foreground Copilot**: Persistence ensures protection even with the screen off.

## Safety Warnings
- Do not use voice commands in heavy traffic at high speeds.
- Ensure your helmet fits correctly to hear audio feedback clearly.
- LogPose is an assistant, not a replacement for rider attention.
